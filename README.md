# MovieIQ — Predictive Analytics on Film Success

An end-to-end ML project + Streamlit dashboard predicting whether a movie will
be commercially successful (revenue > budget) from its budget, popularity,
runtime, rating, and genre.

## Project structure

```
MovieIQ/
├── MovieIQ.py              # Streamlit dashboard — SELF-CONTAINED (Stage 5)
├── analysis.py             # Optional: Stages 1-4 as a standalone script/report
├── movies.csv               # raw input data (the ONLY data file MovieIQ.py needs)
├── requirements.txt
├── ANSWERS.md               # written answers to every project question
├── assets/                  # saved EDA/model charts, generated by analysis.py
└── model/                   # trained model + encoders, generated by analysis.py
```

**Important:** `MovieIQ.py` is fully self-contained — on startup it cleans
`movies.csv`, runs the statistical tests, and trains the Random Forest itself
(cached, so it only happens once per session). It does **not** depend on
`movies_clean.csv`, `results.json`, or anything in `model/` — those are only
produced by `analysis.py` for offline reporting/reproducibility. This means
the only two files that must exist in your deployment are `MovieIQ.py` and
`movies.csv` (plus `requirements.txt` for the installer).

## Setup

```bash
pip install -r requirements.txt
```

## Run the dashboard (Stage 5)

```bash
streamlit run MovieIQ.py
```

Then open the URL Streamlit prints (typically http://localhost:8501).

## Reproduce the full written analysis (Stages 1-4, optional)

Only needed if you want the saved chart PNGs in `assets/` and a
`results.json` for offline reference — the dashboard itself doesn't need this:

```bash
python analysis.py
```

## Deploying to Streamlit Community Cloud

1. Push the repo to GitHub with **`MovieIQ.py`, `movies.csv`, and
   `requirements.txt` all at the root of the repo** (not nested in a
   subfolder) — Streamlit Cloud looks for `requirements.txt` next to your
   main app file.
2. Go to [share.streamlit.io](https://share.streamlit.io), connect the repo,
   and set the main file path to `MovieIQ.py`.
3. Streamlit Cloud installs `requirements.txt` automatically.
4. If you ever see a `ModuleNotFoundError` or `FileNotFoundError` after
   deploying, it almost always means a file isn't actually at the repo root
   next to the app file — check the repo listing on github.com directly, and
   use **Manage app → Reboot app** after fixing it, since a simple git push
   doesn't always trigger a clean rebuild.
5. Paste the live URL into `ANSWERS.md` once deployed.
